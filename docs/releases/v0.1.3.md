Update release of **iPanicX**: the app now keeps itself up to date.

### What's new

- **Automatic updates.** At launch (at most once a day), iPanicX asks GitHub for its latest release. When a new version is out, an **Update** row appears in the sidebar; **General › Updates** shows what's new and installs it with **Install and Restart**:
  - the package for your computer is downloaded and checked against the release's SHA-256 checksums (nothing is installed if they differ);
  - iPanicX quits, replaces itself and restarts. If anything goes wrong, the previous version is put back.
- The check can be turned off in **General › Updates**, and run by hand with **Check Now**. It is the only network request iPanicX makes: nothing about you or your devices is sent.

This version must be installed by hand one last time; the next ones install themselves.

On macOS, keep iPanicX in the **Applications** folder: an app run from Downloads cannot replace itself (iPanicX then opens the release page instead).

### Download

| | File |
|---|---|
| Windows 10/11 (x64) | `iPanicX-0.1.3-windows-x64.zip` |
| macOS 12+ | `iPanicX-0.1.3-macos.dmg` (or `.zip`) |

**Windows**: unzip and run `iPanicX.exe`. Install **Apple Devices** from the Microsoft Store (or iTunes) first: it provides the iPhone USB driver.

**macOS**: drag iPanicX to Applications. The bundled tools are built for Apple Silicon; on an Intel Mac, run `brew install libimobiledevice`.

The app is **not signed** yet: on Windows choose *More info → Run anyway*; on macOS open it once, then *System Settings → Privacy & Security → Open Anyway*.

A diagnosis should always be confirmed by hardware inspection. `SHA256SUMS.txt` lists the checksums of the files.
