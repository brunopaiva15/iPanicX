Bug-fix and detail release of **iPanicX**.

### What's new

- **App crashes in detail.** Every crash report is now read in full, not just counted:
  - the cause in plain language (froze / watchdog `0x8badf00d`, too hot `0xc00010ff`, memory error, aborted, too much CPU or memory, killed by iOS…);
  - the pattern of the period: *mostly one app* (a problem with that app, not the iPhone), *many apps including Apple's with memory errors* (possible iOS or hardware issue), or *overheating*;
  - a new **App crashes** screen (7 days / 30 days / all) with crashes per day, by app and by cause, and every crash with its technical details and raw report. Open it from **Health › App crashes** or from the top of **Panics**.
- **Buttons show a spinner** while their action runs (*Check Again*, *Retry*, *Refresh*…).

### Fixes

- **iOS 26 SMC panics**: the new sensor list format (`S.sensor array 0 - 5 is 0, 1310720, 0, 0, 0`) is now read correctly, so e.g. an iPhone 14 Pro `0x140000` panic gets its precise diagnosis (charging port flex / power button flex, high confidence) instead of the generic one.
- **Free storage**: iOS reports several "available" counters that can disagree; iPanicX now uses the smallest one, like iOS Settings (it could show far more free space than real).
- **Battery temperature**: more iOS versions are supported.
- **Health › Technical details** now lists the raw battery and storage values iOS returned, to help diagnose any remaining *Not available*.

### Download

| | File |
|---|---|
| Windows 10/11 (x64) | `iPanicX-0.1.1-windows-x64.zip` |
| macOS 12+ | `iPanicX-0.1.1-macos.dmg` (or `.zip`) |

**Windows**: unzip and run `iPanicX.exe`. Install **Apple Devices** from the Microsoft Store (or iTunes) first: it provides the iPhone USB driver.

**macOS**: drag iPanicX to Applications. The bundled tools are built for Apple Silicon; on an Intel Mac, run `brew install libimobiledevice`.

The app is **not signed** yet: on Windows choose *More info → Run anyway*; on macOS open it once, then *System Settings → Privacy & Security → Open Anyway*.

A diagnosis should always be confirmed by hardware inspection. `SHA256SUMS.txt` lists the checksums of the files.
