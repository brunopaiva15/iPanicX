Battery release of **iPanicX**.

### What's new

- **Battery information read from more sources**, so health, cycle count and capacities show on more iPhones:
  - the battery gas gauge diagnostics (cycle count, design and full-charge capacity) are now read too, and merged with the IORegistry battery entry;
  - older iPhones without that entry fall back to the charger entry;
  - these queries now have 30 s to answer (the battery entry is large on recent iPhones and could time out before).
- **Maximum capacity** now uses the same value as *Settings › Battery › Battery Health* on the iPhone.
- **Health › Technical details** also lists the raw gas gauge and charger values.

If you installed 0.1.3, iPanicX offers this update itself: **Update 0.1.4** in the sidebar, then **Install and Restart**.

### Download

| | File |
|---|---|
| Windows 10/11 (x64) | `iPanicX-0.1.4-windows-x64.zip` |
| macOS 12+ | `iPanicX-0.1.4-macos.dmg` (or `.zip`) |

**Windows**: unzip and run `iPanicX.exe`. Install **Apple Devices** from the Microsoft Store (or iTunes) first: it provides the iPhone USB driver.

**macOS**: drag iPanicX to Applications. The bundled tools are built for Apple Silicon; on an Intel Mac, run `brew install libimobiledevice`.

The app is **not signed** yet: on Windows choose *More info → Run anyway*; on macOS open it once, then *System Settings → Privacy & Security → Open Anyway*.

A diagnosis should always be confirmed by hardware inspection. `SHA256SUMS.txt` lists the checksums of the files.
