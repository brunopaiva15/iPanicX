Device information fixes for recent iPhones, checked against a real iPhone 14 Pro on iOS 26.

### Fixes

- **Storage capacity** now matches *Settings › General › iPhone Storage* (e.g. 256 GB instead of 235 GB): iPanicX uses the disk size iOS reports, not only the data partition.
- **Battery health** only uses capacities in mAh. On iOS 26 the battery gas gauge reports its full-charge capacity as a percentage, which could give a wrong health value when it was the only source.
- **Developer Mode** is read again on recent iOS versions.
- **Battery temperature**: iOS 26 no longer sends it. iPanicX now says *Not reported by iOS* instead of *Not available*.
- **Health › Technical details**: very long raw values are shortened.

If you use 0.1.3 or later, iPanicX offers this update itself: **Update 0.1.5** in the sidebar, then **Install and Restart**.

### Download

| | File |
|---|---|
| Windows 10/11 (x64) | `iPanicX-0.1.5-windows-x64.zip` |
| macOS 12+ | `iPanicX-0.1.5-macos.dmg` (or `.zip`) |

**Windows**: unzip and run `iPanicX.exe`. Install **Apple Devices** from the Microsoft Store (or iTunes) first: it provides the iPhone USB driver.

**macOS**: drag iPanicX to Applications. The bundled tools are built for Apple Silicon; on an Intel Mac, run `brew install libimobiledevice`.

The app is **not signed** yet: on Windows choose *More info → Run anyway*; on macOS open it once, then *System Settings → Privacy & Security → Open Anyway*.

A diagnosis should always be confirmed by hardware inspection. `SHA256SUMS.txt` lists the checksums of the files.
