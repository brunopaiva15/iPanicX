Diagnosis release of **iPanicX**: a much larger knowledge base, with a source for every entry.

### What's new

- **SMC sensor masks decoded per model** (iPhone 13 to 16 Pro). The *sensor array* code of an `SMC BSC failure` panic now names the part on every covered model, not only the iPhone 14 Pro. Combined codes are split bit by bit (`0x1C0000` on a 14 Pro = charging port + proximity + power button); unreferenced bits and ambiguous codes are shown, never guessed.
- **Missing sensors name their part**: `TG0B`, `TG0V`, `TB0V`, `mic1`, `mic2`, `mic-temp-sens1/2`, `prs0`.
- **42 panic signatures** (21 before): AOP (NMI Power, Bosch audio channel, I²C timeout, no pulse, proximity, Systick, data abort), SMC data abort, AppleSocHot, PMP NMI, SEP ROM, NAND / NVMe / PCIe, WKdm, WDT, battery gas gauge, Wi-Fi, CS42L75 audio codec, Tristar, display (PMU, not detected, DCP), iPad Pro 10.5 display watchdog, undefined kernel instruction, root hash not authenticated, thermalmonitord without missing sensor…
- **I²C panics on iPhone 6 to XR** list the chips on the reported bus (board reference designators, to check on the boardview).
- **Sources and technical reason** are now shown in every diagnosis and in the exported report (iFixit, iPad Rehab, workshop data).

### Download

| | File |
|---|---|
| Windows 10/11 (x64) | `iPanicX-0.1.2-windows-x64.zip` |
| macOS 12+ | `iPanicX-0.1.2-macos.dmg` (or `.zip`) |

**Windows**: unzip and run `iPanicX.exe`. Install **Apple Devices** from the Microsoft Store (or iTunes) first: it provides the iPhone USB driver.

**macOS**: drag iPanicX to Applications. The bundled tools are built for Apple Silicon; on an Intel Mac, run `brew install libimobiledevice`.

The app is **not signed** yet: on Windows choose *More info → Run anyway*; on macOS open it once, then *System Settings → Privacy & Security → Open Anyway*.

A diagnosis should always be confirmed by hardware inspection. `SHA256SUMS.txt` lists the checksums of the files.
