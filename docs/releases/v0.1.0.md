First public release of **iPanicX**: find out why an iPhone keeps restarting.

### What's inside

- **Health check**: battery (health, cycles, capacity, temperature), storage, kernel panics, app crashes and memory events over the last 7 days, NAND, baseband, Developer Mode. No made-up score: each line is OK / attention / problem, or *Not available* when iOS does not expose it.
- **Kernel panic diagnosis** with suspected parts, possible causes and recommended actions.
- **Correlation**: panics grouped by hardware clue (missing sensor such as `TG0B`, SMC sensor mask, watchdog service), with occurrences and first / last seen.
- **Live console** with important lines highlighted and explained.
- **History**: compares each scan with the previous one.
- **Reports**: plain-text diagnosis and full device report.
- Clear guidance when the iPhone is not detected (missing Apple driver, stopped service, USB driver error).
- English and French.

Everything runs locally: no account, no analytics, no network requests.

### Download

| | File |
|---|---|
| Windows 10/11 (x64) | `iPanicX-0.1.0-windows-x64.zip` |
| macOS 12+ | `iPanicX-0.1.0-macos.dmg` (or `.zip`) |

**Windows**: unzip and run `iPanicX.exe`. Install **Apple Devices** from the Microsoft Store (or iTunes) first: it provides the iPhone USB driver.

**macOS**: drag iPanicX to Applications. The bundled libimobiledevice tools are built for Apple Silicon; on an Intel Mac, run `brew install libimobiledevice`.

The app is **not signed** yet: on Windows choose *More info → Run anyway*; on macOS open it once, then *System Settings → Privacy & Security → Open Anyway*.

### Known limitations

- First release: the Windows and macOS builds were produced by CI and have not been tested on every setup. Please open an issue with a screenshot of *Technical details* if something goes wrong.
- Battery and storage details depend on what the iPhone's iOS version exposes.
- A diagnosis should always be confirmed by hardware inspection.

`SHA256SUMS.txt` lists the checksums of the files.
